# Quiet Book Seeder

> Seed wide quotes on fresh prediction markets with risk caps and board-ready evidence.

## Overview

Prediction market venues list long tails of new event contracts that sit with wide spreads and little two-sided liquidity before professional makers arrive. A conservative seeder can rest broad bids and asks, earn the spread or venue maker incentives, and stop when adverse selection becomes obvious. The hard part is not quoting; it is proving to a small security team and skeptical auditors that the automation stayed inside policy limits.

Quiet Book Seeder is a paper-first market-making pilot for newly listed prediction markets. It discovers fresh books, posts configurable wide quotes with maximum size, inventory caps, daily loss stops, and a kill switch, then records every quote, cancel, fill, price move, config version, and risk decision in a local audit log. The output is a one-page board slide: gross spread capture, net P&L after fees, worst drawdown, pickoff score, exception count, and the exact controls that prevented larger losses.

Why now: event-market APIs are maturing, maker incentives exist on some venues, and the long tail of new markets is too thin for high-frequency teams to bother. For a regional bank CISO, this is not a trading platform; it is a low-capital cloud experiment that demonstrates automated risk control, evidence export, and measurable economic return in a format regulators can understand.

## Market Analysis

Newly listed prediction markets have predictable early liquidity gaps, but small teams lack a safe quoting harness with audit artifacts. The gap is not alpha; it is controlled entry plus proof that risk limits worked. It appeals to fintech labs, market makers testing venues, and bank security teams needing board-ready evidence for cloud automation pilots.

## MVP Scope

Includes one venue connector (Kalshi or similar public event market) in paper mode by default with optional manual live mode, discovery of markets created in last N hours with wide mid spread, quote engine posting bid/ask offsets, max order size, inventory cap, daily loss stop, kill switch, SQLite audit log, and CSV/PDF board slide export. Excludes multi-venue trading, latency optimization, machine-learning alpha, automatic funding, legal compliance signoff, production deployment to bank core systems, and custody of customer funds.

## Getting Started

### Prerequisites

- Python 3.12+
- [uv](https://docs.astral.sh/uv/) (recommended) or pip


### Installation

```bash
git clone https://github.com/rayketcham-lab/quiet-book-seeder
cd quiet-book-seeder

# Using uv (recommended)
uv venv && source .venv/bin/activate
uv pip install -e ".[dev,test]"

# Or using pip
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev,test]"
```

### Running

```bash
uvicorn quiet_book_seeder.app:app --reload
```

### Testing

```bash
pytest tests/ -v
```
